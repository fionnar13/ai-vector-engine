### 2.1 Runtime (authoritative): `src-js/tools.js:973-999` — `inferSemanticTool`

  `permissions:{read:['semantic'], write:[]}`, `deterministic:true`.
- Actual input shape: `{ objectIds: string[] }` — exactly one field; array of object ids; `required:['objectIds']`.
- Validation (tools.js:975):
  - `!Array.isArray(input.objectIds) || input.objectIds.length<1` → error `{code:'VALIDATION_SCHEMA', message:'objectIds >=1'}`.
  - `validateObjectsExist` (tools.js:179-187): each id is checked against `context.workingCopy.getObject(oid)` or `context.objectStore.get(oid)`; missing id → `{code:'TOOL_PRECONDITION_FAILED', message:'Object not found <id>'}`. Guard: if context has neither surface, existence validation is silently skipped (tools.js:181).
- YES — the input IS validated against existing objects (tools.js:975 → :179-187), and again per-id inside execute:
  geometry unresolvable → `return {success:false, errors:[{code:'TOOL_PRECONDITION_FAILED', message:'Geometry not resolvable for object <oid>', toolId:'T20', objectIds:[oid]}]}` (tools.js:980).
- Failure behavior: validation failures short-circuit BEFORE execute (registry validate path, tools.js:1034+); execute-level unresolvability returns the success:false envelope above; `inferSemantic` itself never throws (total function, semantic.js:122-280).
- Execute reads (per object, tools.js:979-992): geometry via `getGeomOf(context, oid)`; appearance via `workingCopy.getAppearance` else `appearanceStore.get` (null if neither, :982-983); scene node via `sceneGraph.findNodeByObjectId` (:984); world bbox via `getWorldBBoxForObject` (:985); builds `sceneContext={isText, textContent, childCount, parentId, bbox?}` (:986-992).   - `evidence` (:276) — array of `{signal, description, weight}` sorted by signal then description (:263-267); no-evidence branch → `[{signal:'geometry_type', description:'insufficient evidence', weight:0}]` (:246).
