## B5. Mutation Tools (the ONE tool)

- **toolId 'T06', name 'transform_objects'** (tools.js:327-345) — the only tool in
  T01-T15 whose mutation can move a role.
- **Input contract** (tools.js:328): `{objectIds* (array), transform* (object)}`;
  outputSchema `{transformed: array}`; `permissions {read:['sceneGraph'], write:['transaction']}`;
  `deterministic:true`; `category:'mutation'`.
- **Exact matrix shape for scale**: `transform = {a, b, c, d, tx, ty}` — all six keys
  mandatory numbers (validator :333). Convention (tools.js:82-88, Y-down column vectors):
  `x' = a·x + c·y + tx`, `y' = b·x + d·y + ty`. Uniform scale by factor s about a fixed
  point (cx, cy): `{a:s, b:0, c:0, d:s, tx:cx·(1−s), ty:cy·(1−s)}`; about the origin:
  `tx=ty=0`. Area multiplier = |det| = |a·d − b·c| (= s² for uniform scale) — EXACT for
  rect re-fit under axis-aligned/uniform scale (:90-96); for ellipses the radii scale by
  the column norms |(a,c)| / |(b,d)| (:97-100), whose product equals |det| when b=c=0 —
  shear makes the area multiplier shape-dependent, so the contract pins UNIFORM scale
  (b=c=0, a=d=s) as the capability's matrix form.
- **Local-only** (A4 §2 finding, re-verified): T06 applies `input.transform` directly to
  LOCAL parametric coordinates (tools.js:339 → transformGeometryParams :86-88); unlike
  T08/T09 there is NO world/local conversion inside the tool (`worldDeltaToLocal`
  :164-171 is used at :420/:477 only). Host obligations: (a) pre-compose the parent world
  transform when the target is nested (PHASE G #17); (b) compute the required matrix from
  the SAME measure the threshold reads — the world bbox area (tools.js:992) — so that the
  post-mutation world area provably crosses the intended threshold with margin.
- **Determinant guard**: `det = a*d − b*c; if (Math.abs(det) < 1e-12) → TRANSFORM_SINGULAR`
  at VALIDATION time (:333) — before any transaction, before any write.
- Per-type parametric writes: rect corners transformed + axis-aligned re-fit, rx/ry ×
  sqrt|det| (:90-96); ellipse center mapped, radii by column norms (:97-100); line
  endpoints (:101); polygon points (:102); star center + radii × sqrt|det| (:103-106);
